## Aprendizados / armadilhas
- **`%~dp0` SEMPRE termina em `\`** — `"%~dp0"` cru quebra o argumento; usar `"%~dp0."`.
- **Padrão de backup na pasta-pai:** não dá para aninhar `<rootname>` sob `parent(root)` (= a própria raiz). E mudar o padrão exige mover o rollback default junto.
- **ASU: editar≠criar** — editar é barato (instrução pequena); criar novo é antipadrão (mais caro/frágil que entregar para baixar), salvo bundle.
- **Erro "casou 0 vezes" após aplicar** é feature, não bug: o localizador não acha o padrão já modificado e avisa, em vez de reaplicar errado.
- **Regressão do IDEAS:** desta vez o pacote TINHA minhas edições anteriores (aplicadas). Continuar conferindo a cada volta.
