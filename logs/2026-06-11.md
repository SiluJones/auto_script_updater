Tabela comparativa dos agentes: Aider (search/replace + fuzzy + "did you mean"), Claude Code (string exata e única — espírito da nossa DEC-011), Cursor (modelo de apply dedicado). "**AutoCoder**" é nome de ~6 projetos distintos (modelo HumanEval da bin123apple, GitHub Actions de geração por issue, CLIs ChatGPT…) — nenhum traz mecanismo de patch além do que o V4A/Aider já cobrem; reportado ao usuário.
- **DEC-014 — erro acionável, nunca fuzzy silencioso:** implementado `_whitespace_hint` nas âncoras do `replace_context_block` — se a âncora não casa exato mas existe trecho equivalente módulo whitespace (tab×espaços, 4×8), o erro aponta a LINHA e mostra a forma EXATA para copiar. Combina a conveniência do V4A com a segurança do match exato. Fuzzy opt-in registrado em IDEAS.
- **`python -m src self-test`:** valida a instalação ponta a ponta (demo em tempdir: aplica, confere, reverte). 1 comando de confiança pós-instalação.

## Aprendizados / armadilhas
- A lição mais valiosa do V4A não é o formato — é o **contrato de erro**: mensagens que dizem exatamente qual âncora falhou transformam o modelo gerador em parte do loop de correção. Nossa tabela §6 + dica de whitespace implementam isso.
- Kit "autocontido" é requisito literal: qualquer referência a arquivo do repo quebra quando o guia é copiado para outro projeto.
- `&` de background no dash quebra encadeamento com `cd` — usar caminhos absolutos em comandos compostos.
