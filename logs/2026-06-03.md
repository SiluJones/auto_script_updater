## Feito

- Pesquisadas alternativas para manipulação de arquivos Python (ast, libcst, rope, regex) → libcst 1.8.6 selecionado (preserva formatação, produção-proven, ativo, MIT).
- Analisadas alternativas de formato de instrução (YAML, JSON, TOML) → YAML selecionado (blocos multiline `|`, comentários, legível para IA e humanos).
- Definida arquitetura modular completa: `core/` (6 módulos), `strategies/` (3 + base), `gui/` (4 módulos), `schemas/`.
- Especificadas 11 estratégias de modificação para 4 tipos de arquivo.
- Definido schema conceitual do arquivo de instrução YAML v1.0 com hierarquia: cabeçalho, settings, files[], modifications[].
- Documentadas 7 decisões arquiteturais em ADR format (DEC-001 a DEC-007).
- Gerada documentação completa do projeto: CONTEXT.md, STATUS.md, DECISIONS.md, CHANGELOG.md, IDEAS.md, LOG-TEMPLATE.md, ROADMAP.md, GLOSSARY.md, HISTORICO.md, logs/2026-06-03.md.

## Decisões
- **DEC-001:** Localização por identificador semântico / janela de contexto, nunca número de linha absoluto.
- **DEC-002:** Padrão Strategy (ABC) para estratégias de modificação por tipo de arquivo.
- **DEC-003:** libcst para manipulação Python, não ast stdlib.
- **DEC-004:** YAML como formato canônico de instrução.
- **DEC-005:** PySide6 como framework GUI.
- **DEC-006:** Backup obrigatório antes de qualquer escrita em disco.
- **DEC-007:** Versionamento de schema com campo `format_version`.

## Aprendizados / armadilhas
- Número de linha como localizador é o erro mais óbvio e mais comum em ferramentas deste tipo — documentada como Armadilha #1 no CONTEXT.md.
- `ast.unparse()` destrói comentários e formatação ao reescrever Python — libcst é obrigatório → Armadilha #2 no CONTEXT.md.
- Caminhos Windows com `\` em YAML precisam de `\\` ou `/` — a IA geradora precisa saber disso → Armadilha #6 no CONTEXT.md.
- Encoding ambíguo em Windows (UTF-8 vs CP-1252) é armadilha real em arquivos de usuário → Armadilha #3 no CONTEXT.md.
- Modificações interdependentes no mesmo arquivo precisam de reparse entre si, não apenas aplicação sequencial → Armadilha #4 no CONTEXT.md.
- Pattern regex não-único pode aplicar modificação no lugar errado → validação de unicidade obrigatória antes de executar → Armadilha #5 no CONTEXT.md.
- OpenAI Codex usa context-based patching (não linha) há anos — confirma nossa abordagem; `apply-patch-py` é referência de implementação → registrado em HISTORICO.md §1.
